⌨️ Hardware & Function Key Guide

Quick Reference

The Casio mobile scanner keypad maps directly to physical function shortcuts for rapid one-handed counting:

F1
Change Config / Exit
Opens the Host URL and Store Code setup dialog or exits to OS.
F4
Finish / Back to Scan
Finalizes the current locator count or toggles back to active scanning.
F6
View Scan
Opens the itemized audit table of all products scanned in this shelf.
F7
Clear / Delete
Clears the active input field or removes a selected item row.
