📊 Store Inventory Progress & Session Cards

Real-time tracking of branch counts, locator closures, and synchronization workflows.

🔵 ONGOING Store Session
Indicates the physical count is currently in progress. Handheld mobile scanners are actively scanning barcodes into open locators.

Action Available: ☁️ Pull Cloud Session allows importing cloud counts to a local workstation.
🟢 FINISHED Store Session (100%)
All locators in the store have been verified and closed by the host administrator. The count is ready for Excel variance export and consolidation.

Action Available: 🔄 Re-open Store allows unlocking locators if recounts or item corrections are needed.
🔴 CLOSED Store Session
The session has been archived. Operators can no longer log in or scan into this branch unless an administrator explicitly clicks Re-open Store.
☁️ Download Store Session from Cloud
A dedicated button located at the top-right of the progress section (visible only on local servers) that lets you download any branch session from the central cloud database by entering the 3-letter store code.

⚠️ Pending Cloud Sync Approvals

How the cloud server protects active inventory counts from accidental data overwrites.

Why Sync Approvals Exist: When a local branch synchronizes to the central cloud, if that branch's data already exists on the cloud with prior scan records, the cloud server automatically holds the request in a pending state to prevent unintended overwrites.
1
Branch Submits Sync
Local host finishes store counts and clicks 'Sync to Cloud' in the Host Console.
2
Cloud Detects Conflict
Cloud checks existing record count. If records exist, a Pending Sync Request is created.
3
Admin Review
System Administrator reviews the store code, record count, and timestamp on the dashboard.
4
Approve / Commit
Clicking 'Approve' commits the overwrite and applies the latest local scan counts to the cloud database.

🔄 Complete Store Inventory Lifecycle

Recommended operational sequence from initial store setup to final variance report export.

1
Initialize Store
Click 'Create / Select Store' on the Dashboard and enter the 3-letter Store Code (e.g. RME).
2
Load Masterfile
Verify products in 'Items Masterfile' or click 'Sync Masterfile from Cloud' to download latest catalog.
3
Perform Scans
Operators log into mobile scanners and scan barcodes into their assigned locators.
4
Close Locators
As shelves are counted, close locators individually or click '🔒 Close All Open' to finish the store.
5
Consolidate & Sync
Export Excel variance report, print summary audit sheets, and sync final count to Cloud.
